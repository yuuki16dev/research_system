      【必須】Google Gemini API キーの無料取得手順

      クレジットカード登録不要・完全無料（1日1,500回まで$0）で誰でも3分で取得できます。

      Google AI Studio を開く ↗
      Step 1
      公式サイトにアクセス

      Google AI Studio を開き、お持ちのGoogleアカウント（Gmail等）でログインします。

      Step 2
      APIキーを発行してコピー

      画面の青い「Create API key」を押し、「Create in new project」を選んで生成されたキーをコピーします。

      Step 3
      アプリに貼り付けて保存

      本アプリの「⚙️ 設定」➔「Gemini APIキー」に貼り付け、「接続テスト」➔「保存」を押せば完了です！

      2

      【任意】Tavily Search API キー（Web深層検索の強化）

      ※本アプリはキー不要の DuckDuckGo を内蔵しているため、未設定でも全機能が動作します。

      Tavily 公式 ↗

      より大量のWebサイトや最新ニュースを高速・高精度に巡回させたい場合のみ、Tavily公式サイト で無料登録（月1,000回無料）してキーを設定してください。

      💡 よくある質問 ＆ トラブルシューティング

      Q. お金が勝手に請求される心配はありませんか？

      クレジットカード登録画面自体がないため、勝手に請求されることは100%ありません。無料枠上限に達した場合は一時停止するだけです。

      Q. 「APIキーが無効です」とエラーが出ます

      キーの前後に余分なスペースが入っていないかご確認ください。キーは通常 AIzaSy から始まります。また、個人のGoogleアカウントでお試しください。

      Q. アプリをアップデートしたら設定は消えますか？

      消えません。設定や履歴は Windows の共通データ領域（%APPDATA%\ResearchStudio\）に安全に保管されるため、自動で引き継がれます。
