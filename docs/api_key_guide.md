## 0. はじめに（安心の完全無料設計）

本アプリ（Research Studio）は、Google の最先端AI **「Gemini 1.5 Flash」** を使用してリサーチ・構造化分析を行います。

| 項目 | 内容 |
| :--- | :--- |
| **必要なもの** | お手持ちの **Google アカウント**（Gmail等のアカウント）のみ |
| **利用料金** | **完全無料（$0）**（1日あたり1,500回まで無料で利用可能） |
| **クレジットカード登録** | **一切不要**（勝手に課金される心配はゼロです） |
| **所要時間** | **約3分**（1回設定すれば、次回以降は自動で保存されます） |

## 1. 【必須】Gemini API キーの無料取得手順（3ステップ）

### ステップ 1: Google AI Studio（公式）にアクセス
1. ブラウザで以下のリンクを開きます（※Googleアカウントでログインしてください）。  
   👉 **[Google AI Studio - APIキー管理ページ](https://aistudio.google.com/app/apikey)**
2. 初めてアクセスした場合は、利用規約の同意画面が表示されますので、チェックを入れて「**Continue**（または同意）」をクリックします。

---

### ステップ 2: APIキーを発行する
1. 画面上部にある青いボタン **「Create API key」**（または「APIキーを作成」）をクリックします。
2. ポップアップが表示されます：
   - **「Create API key in new project」**（新しいプロジェクトで作成）を選択します。
   - 数秒待つと、画面に英数字が並んだキー（例: `AIzaSy...`）が生成されます。
3. キーの横にある **「Copy」**（コピー）アイコンをクリックします。  
   ※クリップボードにキーがコピーされます。

---

### ステップ 3: Research Studio に貼り付けて保存
1. **Research Studio** を起動します。
2. 画面右上にある **「⚙️ 設定」** ボタンをクリックして設定モーダルを開きます。
3. **「Gemini APIキー」** の入力欄に、先ほどコピーしたキーを貼り付け（`Ctrl` + `V`）ます。
4. **「接続テスト」** ボタンをクリックします。  
   👉 `「✅ 接続成功！Gemini 1.5 Flash で正常に動作します」` と表示されれば完了です！
5. 最後に **「保存」** ボタンをクリックします。

> 💡 **ポイント**:
> 一度保存すれば、Windowsの安全なユーザー領域（`%APPDATA%\ResearchStudio\`）に保存されるため、次回アプリ起動時や新バージョンに更新した際も再設定の必要はありません。

## 2. 【オプション】Tavily API キーの取得手順（Web深層検索の強化）

> ⚠️ **ご注意**: **Tavily は必須ではありません！**  
> 本アプリは初期状態で **DuckDuckGo（キー不要・完全無料）** が動作するため、この設定をスキップしても全機能が問題なく使えます。

「より大量のWebサイトや最新ニュースを高速・高精度に巡回させたい」場合のみ設定してください。

1. **[Tavily 公式サイト](https://tavily.com/)** にアクセスします。
2. 右上の **「Sign Up」** をクリックし、Googleアカウントまたはメールアドレスで無料登録します（クレジットカード不要）。
3. ダッシュボードに表示される **「API Key」**（`tvly-...`）をコピーします。
4. Research Studio の **「⚙️ 設定」** ➔ **「Tavily 検索キー」** に貼り付けて保存します（月1,000回まで完全無料）。

## 3. よくある質問 ＆ トラブルシューティング（困ったときは）

### Q1. お金が勝手に請求されることは本当にありませんか？
**A. 100% ありません。**  
Google AI Studio の無料枠は、クレジットカード情報の入力自体が不要な仕様になっています。1日の上限（1,500回）に達した場合は一時的にリクエストが休止するだけで、課金されることは絶対にありません。

### Q2. 「APIキーが無効です」とエラーが出ます
**A. 以下の3点をご確認ください：**
1. **前後に余分な空白が入っていないか**: コピー時にスペースが含まれている場合があります。入力欄を一度空にして貼り直してください。
2. **キーの頭文字**: Gemini API キーは通常 `AIzaSy...` から始まります。別の文字列になっていないか確認してください。
3. **Google アカウントの制限**: 会社や学校のGoogle WorkspaceアカウントではAPI発行が制限されている場合があります。その場合は個人のGoogleアカウント（`@gmail.com`）でお試しください。

### Q3. 新しいバージョンにアップデートしたら設定は消えますか？
**A. 消えません。**  
`v1.5.0` 以降、APIキーや過去のリサーチ履歴は Windows の共通データ領域に安全に保管されます。新しいバージョンの ZIP をどこに解凍しても自動で引き継がれます。

## 4. 配布形態別ガイドの活用方法

### 【GitHub版（開発者・自力ビルド向け）】
- アプリ画面上の「⚙️ 設定」モーダルからの保存に加え、環境変数ファイル `.env` をプロジェクト直下に作成して設定することも可能です：
  ```env
  GEMINI_API_KEY=AIzaSyYourKeyHere
  PORT=3939
  ```

### 【BOOTH版（完成品EXE・一般購入者向け）】
- 本ドキュメントの内容を、スクショ付きの **「スタートガイド.pdf」** としてZIPファイルに同梱します。
- 黒い画面（コマンドライン）や環境変数設定を一切見せることなく、ブラウザ上の設定画面だけで完結するため、PC初心者でも安心して導入いただけます。
