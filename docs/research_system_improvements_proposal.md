## 1. 評価指標と達成目標
* **ターゲットユーザー**: ビジネスパーソン（新規事業企画・マーケター・コンサル・経営層・エンジニア・個人開発者・副業者）
* **成功指標**: **「100人中80人が『驚異的なコストパフォーマンスだ』と感じ、Googleでの手動検索に戻れなくなること」**
* **ROI（投資対効果）の基準**: 
  手動で実施すると**「3〜5時間」**かかる情報収集・精査・比較表作成・資料化の工程を、本システムが**「2〜3分」**で90%以上の完成度まで引き上げること（時間単価3,000円換算で1回の利用あたり約10,000円相当の価値を創出）。

### 人間が手動検索で最も時間とストレスを奪われている「4大ボトルネック」
| ボトルネック | 手動検索での実態 | 本システムでの解決策 |
| :--- | :--- | :--- |
| **① キーワード試行錯誤** | 適切な語句が分からず、何度も検索語を変えて5〜10回検索する | **AIが1つのテーマから多角的なサブクエリを5〜8本自動展開（並列検索）** |
| **② ファクトチェック・拾い読み** | SEO記事や広告を何十サイトも開き、信憑性や一次情報を確認する | **インライン引用番号 [1][2] と情報源信頼度バッジ（公式・統計・ニュース）** |
| **③ 比較表・データの整理** | バラバラのページの数値をExcelやメモに手作業で転記・整形する | **横断比較マトリクス（フィルタ・並替付き）と完成版Excelの即時出力** |

## 3. 【機能面】の改善項目（圧倒的コスパを実現する7つの柱）

1. **AI多角クエリ並列展開（Sub-queries Planner）**:
   ユーザーが1行入力するだけで、AIが「市場規模」「導入費用」「成功/失敗事例」「リスク」「2026年動向」など5〜8個のサブクエリを自動生成し、同時に並列検索。手動で30分かけて何回も検索する手間を1発でゼロにする。
2. **インライン引用・ソースグラウンディング**:
   各文章や表のセルに `[1]` `[2]` を付与。ホバーで元記事タイトル・抜粋が表示され、クリックで即ジャンプ。裏取りの時間を90%削減。
3. **リサーチ目的別プリセット（1クリック設定）**:
   「⚔️ 競合比較」「💡 新規事業・市場調査」「🛠️ ツール選定・料金比較」「⚠️ リスク・落とし穴」「📈 2026年最新トレンド」のワンタップ適用。
4. **用途別・即戦力アウトプット（成果物化の自動化）**:
   「💬 Slack/Teams用1分サマリー」「📑 スライド骨子（PowerPoint/Marp形式）」「✉️ 上長への稟議メール文面」をワンクリックコピー。
5. **手持ちファイル（PDF/テキスト/URL）の追加インプット**:
   自社の企画書や競合のPDFをドラッグ＆ドロップし、「手元の独自資料 × Web最新情報」を掛け合わせた分析。
6. **セクション単位のピンポイント再生成・加筆**:
   レポート内の「比較表だけ行を増やす」「デメリットだけもっと詳しく」を部分的に追加深掘り。
7. **テーマの定点観測（差分トラッキング）**:
   定期的に追いたいテーマを登録し、前回の調査時からの「新着ニュース・差分」だけをハイライト表示。

## 4. 【UI・UX面】の改善項目

1. **エージェント思考プロセスのリアルタイム可視化**:
   AIがどのサイトを巡回し、どう推論したかをターミナル風に表示し、「人間が何時間もかかる作業を肩代わりしてくれている」という圧倒的な満足感を醸成。
2. **インタラクティブ比較マトリクス**:
   表の列並び替え（ソート）、キーワード絞り込み、「表だけをTSV/Excel形式でコピー」ボタン。
3. **事前アウトライン確認（手戻りゼロ化）**:
   ディープリサーチ実行前に、AIが提案する目次案をユーザーが確認・微調整できるモード。
4. **商用PDFプレビューのさらなる洗練**:
   表紙・目次・ページ番号・発行者情報が完璧に整った、クライアントにそのまま提出できるPDF。
