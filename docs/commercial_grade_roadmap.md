## 2. 現状のギャップ分析（有料レベルとの差分）

現状の Research Studio は「検索・分析・テキスト構造化」のエンジンとしては極めて堅牢ですが、**「有料ソフトウェアとしての驚き（WOW要因）」** において以下の 5 大ギャップが存在します：

```
┌─────────────────────────────────────────────────────────────┐
│              有料販売レベルへの 5 大ギャップ                │
├─────────────────────────────────────────────────────────────┤
│ 1. 視覚的表現力 (Visual)   : グラフ・チャート・マインドマップが皆無 │
│ 2. 入力手段 (Input)        : キーワード入力のみ（PDF/URL投入不可）  │
│ 3. 資産化 (Knowledge Vault): 過去調査の全文検索・タグ整理が未整備 │
│ 4. 資料化 (Deliverables)   : PPTX / HTMLプレゼンスライドが未実装   │
│ 5. 納品性 (White-Label)    : 自分の会社名/ロゴに差し替えられない   │
└─────────────────────────────────────────────────────────────┘
```

## 3. 次期バージョンアップ・ロードマップ（Stage別詳細プラン）

---

### 🚀 Stage 1 (v1.4.0): 【視覚的知性 & ホワイトラベル商用化】
> **テーマ**: 「開いた瞬間・印刷した瞬間に声が出るリッチレポート」

#### 1. インタラクティブ・チャート & グラフ自動生成 (Visual Intelligence)
- **機能概要**:
  - レポート内の数値データ（市場規模推移、CAGR、競合シェア、比較レーダー）を AI が自動抽出し、**Chart.js / SVG による美しいグラフ** をインライン描画。
  - 例: 「市場規模予測 2024-2030」➔ 美しいグラデーション棒グラフ
  - 例: 「主要3社スペック比較」➔ 5軸レーダーチャート
  - 例: 「導入メリット・デメリット」➔ 視覚的インフォグラフィック
- **商用PDFへの完全連動**:
  - ヘッドレスブラウザ出力時にも、ベクター解像度を維持したまま A4 PDF 内に自動レイアウト。

#### 2. ホワイトラベル・カスタムレポート機能（★有料販売キラー機能）
- **機能概要**:
  - レポート表紙・ヘッダー・フッターの「Research Studio」ロゴ・社名表記を、ユーザー自身の **「自社名 / クライアント名 / 屋号 / プロジェクト名」** にワンクリックで書き換え可能。
  - ブランドカラー（プライマリカラー・アクセントカラー）をコーポレートカラーに自由変更。
  - 免責事項（ディスクレイマー）や機密保持レベル（「CONFIDENTIAL」等）の透かしウォーターマーク設定。
- **提供価値**:
  - マーケターやコンサルタントが **「自社が作成した公式リサーチ資料」としてそのまま顧客・上司に納品・提出できる** ため、これだけでツールの購入単価が一気に跳ね上がります。

#### 3. 特定URLダイレクト調査モード（URL Deep-Dive）
- **機能概要**:
  - 検索窓に `https://...` を入力するだけで、そのサイト・競合LP・製品ページを直接クローリングし、料金・機能・強み・弱みを即座に丸裸にする競合分析モード。

---

### 🧠 Stage 2 (v1.5.0): 【インプット拡張 & パーソナル・ナレッジ資産化】
> **テーマ**: 「自分の持っている資料と Web の最新動向が融合する」

#### 1. ファイル投入ディープリサーチ（BYOD: Bring Your Own Data）
- **機能概要**:
  - 社内PDF、決算短信、企画書、論文（.pdf / .txt / .md）をドラッグ＆ドロップ。
  - 「このPDFの弱点を最新のWeb情報で補強して」「この企画書に対する競合製品を調査して比較マトリクスを作って」など、ローカル資料を踏まえた高度なリサーチを実現。

#### 2. 過去リサーチの全文横断検索 & プロジェクト・タグ管理
- **機能概要**:
  - 過去に実行した数十〜数百件のレポートを、キーワードや数値から **インクリメンタル全文検索（0.1秒）**。
  - 「新規事業」「競合A社」「技術スタック」などのフォルダ・タグ分け。
  - 過去レポート同士をマージして「3つのレポートを統合した要約書」を自動合成するクロス分析機能。

---

### 🎯 Stage 3 (v2.0.0): 【プレゼン自動化 & パッケージング完成形】
> **テーマ**: 「調査からプレゼン本番まで、1秒も手作業を挟まない」

#### 1. ワンクリック・HTML5 プレゼンテーションスライド生成 (Slide Deck Mode)
- **機能概要**:
  - 調査結果から、ブラウザでそのまま全画面プレゼンできる **インタラクティブなHTML5スライド**（Reveal.js または独自スライドビューア）を自動生成。
  - タイトル、エグゼクティブサマリー、KPI、比較表、将来シナリオが美しい1枚1枚のスライドカードとして配置され、キーボードの矢印キーで投影可能。
  - PowerPoint (.pptx) 形式での直接エクスポートにも対応。

#### 2. BOOTH / Gumroad 販売用パッケージング
- **配布仕様**:
  - 初回起動時の「3分オンボーディングツアー」（APIキー設定から最初の調査までのチュートリアル）。
  - クリーンなインストーラー / ポータブル版（USBに入れて持ち運べる完全独立設計）。
  - 購入者限定の「高品質プロンプト解説・リサーチ活用ガイド」同梱。
