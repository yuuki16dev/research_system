# Research Studio — AIリサーチ＆商用レポート自動化システム

> **テーマを入れるだけで、Web検索・専門サイト巡回・AI分析を行い、エグゼクティブ要約・比較表・商用A4 PDFまで自動生成する次世代リサーチダッシュボード**

![Research Studio Banner](public/favicon.svg)

---

## ✨ 主な機能と特徴

- **⚡ ワンクリック・高速ディープリサーチ**:
  - 知りたいテーマを入力するだけで、Gemini が論点を自動分解し、Web全体や特定サイト（Zenn, Qiita, 専門メディア等）を横断巡回・ファクトチェック・構造化分析します。
- **💬 Side-by-Side スプリットビュー深掘り対話**:
  - レポート本文や比較表をスクロール閲覧しながら、右側パネルでAIアシスタントと追加対話検索が可能。
  - レポート内の文章をマウスでドラッグ選択するだけで「✨ 引用して深掘り質問」ができます。回答をレポート末尾に即座に追記することも可能。
- **📄 ワンクリック商用A4 PDF直接ダウンロード**:
  - PC内蔵の Edge / Chrome ヘッドレス機能を活用し、印刷ダイアログを挟まずに、表紙・目次・比較表が1ミリも狂わない本物の商用A4ベクターPDFを直接ダウンロードフォルダに保存します。
- **📊 多彩なビジネス出力フォーマット**:
  - **商用PDF** / **Excel (.xlsx)** / **Markdown (.md)** / **Claude連携プロンプト** / **Slack・Teams用要約** / **スライド骨子**
- **⚖️ レポート比較（A/B分析）**:
  - 過去に実行した2つのリサーチ結果をワイドな横並び画面で突合し、エグゼクティブサマリー、重要指標、示唆の差分を瞬時に把握できます。
- **🔒 安全なローカル動作・プライバシー保護**:
  - 調査履歴やAPIキーはすべて手元のPC内（`data/`）にのみ安全に保管されます。外部サーバーへの情報送信はありません。

## 🚀 選べる2つの導入方法（利用環境に合わせて選べます）

お使いのPC環境に合わせて、**「Node.js不要のワンクリック版」**または**「Node.js環境向けソースコード版」**のいずれかをお選びいただけます。

> 💡 **重要: どちらかの方法で起動しない・動作しない場合は、もう1つの方法をお試しください！**  
> お使いの PC のセキュリティ設定（SmartScreen や会社PCの権限）や Node.js 環境によって片方がうまく動かない場合があります。本アプリは**どちらの方法でも全く同じ全機能**が利用できますので、動かない場合は迷わずもう一方の方法をお試しください。

### パターン 1：Node.js が入っていない場合（一般ユーザー向け・推奨 ⭐）

Node.js やコマンドの知識は一切不要です。ダウンロードしてダブルクリックするだけで即座に使えます。

1. **GitHub Releases からダウンロード**:
   - [**GitHub Releases（最新版ダウンロード）**](https://github.com/yuuki16dev/research_system/releases) にアクセスします。
   - `ResearchStudio-win.zip`（または `ResearchStudio.exe`）をクリックしてダウンロードします。
2. **ダブルクリックで起動**:
   - ダウンロードした zip を右クリックして「すべて展開」し、フォルダ内の **`ResearchStudio.exe`** をダブルクリックします。
   - 自動的にブラウザが立ち上がり、**`http://localhost:3939`** にアクセスされます。
   - （※ 設定や履歴は `.exe` と同じ場所に自動作成される `data/` フォルダに安全に保存されます）

> 💡 **初回起動時に「Windows によって PC が保護されました」と表示される場合**:  
> 個人開発・オープンソースのため高額な企業署名を省略しており、Windows SmartScreen の警告画面（青い画面）が表示される場合があります。  
> **「詳細情報」** をクリック ➔ **「実行」** ボタンを押すことで問題なく起動できます。（※ 初回のみ。ウィルス等の有害なコードは一切含まれておりません）

> ⚠️ **もしワンクリック版（.exe）で起動しない・動作しない場合**:  
> セキュリティソフトの誤検知ブロックや Windows 環境の差異で起動しない場合は、**もう1つの方法【パターン 2：Node.js版（start.bat）】**をお試しください。公式サイトから Node.js をインストールして `start.bat` を実行することで、ブロックを回避して確実に起動できます。

### パターン 2：Node.js が入っている場合（開発者・ソースから動かしたい方向け）

リポジトリをダウンロード（またはクローン）して、最新のソースコードから起動します。

1. **ダウンロード または クローン**:
   - **GitHubからZIPで保存する場合**: 画面上部の緑色の「Code」ボタン → **「Download ZIP」** をクリックして解凍。
   - **Git でクローンする場合**:
     ```bash
     git clone https://github.com/yuuki16dev/research_system.git
     cd research_system
     ```
2. **起動する（ワンクリック対応）**:
   - **🪟 Windows**: フォルダ内の **`start.bat`** をダブルクリックするだけ！（依存関係の確認・ブラウザ自動オープンまで全自動で行われます）
   - **🍎 Mac / 🐧 Linux**:
     ```bash
     chmod +x start.sh stop.sh
     ./start.sh
     ```
   - **npm コマンドで起動**:
     ```bash
     npm install
     npm start
     ```
3. ブラウザで **`http://localhost:3939`** が開きます。

> ⚠️ **もし Node.js 版（start.bat）で起動しない・動作しない場合**:  
> 「Node.js が見つからない」「バージョンが古い」「黒い画面のエラーが出る」等で起動できない場合は、**もう1つの方法【パターン 1：ワンクリック版（ResearchStudio.exe）】**をお試しください。Node.js のインストール不要で、ダウンロードした `.exe` をダブルクリックするだけですぐに使えます。

## 🔒 Windows Defender SmartScreen（青い画面）の対処と安全性

### Q. 「Windows によって PC が保護されました」と表示されて起動できません
**A. ご安心ください。以下の手順で簡単に解除・起動できます。**

1. 青い画面の中央にある **「詳細情報」** をクリックします。
2. 右下に隠れていた **「実行」** ボタンが現れるので、クリックします。
3. これにより正常に起動し、次回以降はこのPCで警告は表示されなくなります。

> 💡 **ポイント**: ダウンロードした `ResearchStudio-win.zip` は、必ず **「右クリック ➔ すべて展開」** で解凍してから実行してください（zipの中から直接開くとブロックされやすくなります）。

---

### Q. なぜこの警告が出るのですか？ ウィルスですか？
**A. ウィルス等の有害なコードは一切含まれていません。完全なオープンソースです。**

Windows Defender SmartScreen は、ファイルの中身の危険性ではなく、主に以下の2点によって**機械的に青い警告を出す仕様**になっています：
1. **世界中でのダウンロード累計実績（評判スコア）がまだ蓄積されていない**（初公開の新しいファイルには必ず表示されます）
2. **高額な企業向けコード署名証明書（年間数万〜十数万円）が付与されていない**

本プロジェクトは個人のオープンソースソフトウェアとして完全無料で提供しているため、高額な企業署名を省略しております。すべてのソースコードはこのリポジトリで公開されており、ローカルPC内（`http://localhost:3939`）でのみ完結して動作します。

---

### Q. 会社のPC等で「実行」ボタンが押せない・ブロックされる場合は？
**A. 「パターン 2（Node.js版 / `start.bat`）」をご利用ください。**

企業のセキュリティポリシー等で SmartScreen の警告解除が制限されているPCでは、**Node.js をインストールして「パターン 2」の手順で起動することを推奨します**。  
Node.js 公式プログラムにはあらかじめマイクロソフト認定のデジタル署名が付与されているため、**`start.bat` を使った起動であれば SmartScreen の青い警告は一切出ずにスムーズに起動できます**。

## 🔍 起動しない・エラーが出る場合のトラブルシューティング＆ログ確認

他のPCや異なる環境で「起動しない」「動作が停止した」という場合は、本アプリが自動記録している **診断ログ（ログファイル）** を確認することで、一瞬で原因を特定・解決できます。

### 1. 動作中のログ表示とエラーログの保存・確認方法

- **動作中のリアルタイム表示**:
  サーバー起動中、コンソール（黒い画面）にリサーチの各ステップ（クエリ立案、Web検索件数、AI生成、深掘り対話、PDF出力等）がリアルタイムでストリーム表示されるため、デバッグ中や動作状況を一目で把握できます。
- **ディスク容量に配慮した保存ポリシー**:
  すべての正常ログを無差別にディスク保存するとファイルサイズが肥大化するため、**ディスク（ファイル）として永続保存されるのは「問題（エラー・警告・例外）が発生したログ（`data/logs/error.log`）」のみ**です。正常動作時は余計なログファイルがPC内に溜まらないクリーンな設計となっています。

| ログファイル | 保存場所 | 内容 |
| :--- | :--- | :--- |
| **エラーログ（問題発生時のみ保存）** | **`data/logs/error.log`** | 致命的エラー、起動失敗、例外のスタックトレースおよび直前の動作状況 |

> 🔒 **セキュリティ安心設計**: ログファイルに記録される際、Gemini や Tavily の **APIキーは自動的に伏字（`AIza••••••••••••` / `tvly-••••••••••••`）にマスク** されます。ログファイルをそのまま共有しても秘密情報が漏洩することはありません。

#### ログの確認手順（3つの方法）：
* **【方法 1: エクスプローラーから開く（起動に失敗する場合）】**:
  アプリフォルダ内の **`data` ➔ `logs` ➔ `error.log`** をメモ帳などのテキストエディタで開いてください。
* **【方法 2: Web画面からワンクリック確認・コピー（起動できる場合）】**:
  画面右上の **「⚙️ 設定」** アイコンを開き、下部の **「ログを確認」** ボタンを押すと、直近のエラーログや動作状況を画面上で直接閲覧・コピーできます。
* **【方法 3: ブラウザのURLから直接確認】**:
  ブラウザで **`http://localhost:3939/api/logs`** にアクセスすると、直近のエラーログが JSON 形式で表示されます。

## 🛠️ スタンドアロン実行ファイル（.exe）のビルド

Node.js不要のワンクリック配布用実行ファイル（`dist/ResearchStudio.exe`）を自分でビルドしたい場合は、以下のコマンドを実行します：

```bash
npm run build:exe
```
`dist/` フォルダ配下に Windows 用の `ResearchStudio.exe`（約50MB）が生成されます。これを zip 圧縮して GitHub Releases にアップロードすることで、誰でもワンクリックで使えるアプリとして配布できます。
